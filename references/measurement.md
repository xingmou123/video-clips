# 指标、归属与诊断

## 先确定口径

每份快照包括作品 ID、账号、内容类型、时长、方法版本、发布时间、采集时间、后台统计截止时间、自然/付费流量说明、原字段名与证据位置。原始导出和截图留在项目里，结果追加保存，不覆盖旧快照。

| 指标 | 用途与限制 |
|---|---|
| 播放量 | 触达次数，不是独立人数；“1.2 万”保留近似属性 |
| 2 秒跳出率 | 越低越好；不要改名为 3 秒跳出 |
| 3 秒留存/跳出 | 仅后台明确字段或曲线准确 3 秒点；无值就缺失，不插值 |
| 5 秒完播率/5 秒留存 | 保留平台原名和定义；不是整片完播 |
| 平均播放时长（秒） | 观看深度；不是平均播放占比 |
| 平均观看占比 | 平均观看秒数÷视频秒数；推导值与平台原字段分开，循环播放时可能超过 100% |
| 整片完播率 | 受片长影响，不能单独比较长短片质量 |
| 收藏、分享、关注、有效评论 | 辅助解释价值与人群，不替代线索 |

缺失不是零。账号、题材、长度、发布日期、推广和观众来源可能同时影响指标。先检查限流/审核/可见范围/数据延迟，再解释内容问题。

## 引流漏斗

沿用业务已有微信线索、咨询与订单记录，只补作品归属或引用，不另建一套客户名单。客户身份留在有权限的业务系统；团队方法包只带口径与聚合值。

建议依次记录：内容触达 → 关键词互动/去重私信人数 → 实际新增微信人数 → 有效微信线索 → 有效咨询 → 报名/支付/退款后的结果。各层定义和时间窗口写进项目配置。

- **实际加微**：已有好友/线索记录或可核实的新增证据，不能只凭评论、私信或“他说加了”。
- **有效微信线索**：实际加微，符合业务目标人群，并且有可识别的相关需求。判定依据来自明确沟通或业务记录；缺资料标待判断。
- **有效咨询**：已了解其基础、目标或具体问题，并发生与需求相关的双向沟通；单发资料不自动算咨询。
- **报名与支付**：报名意向、订单、实付、退款分开。归属采用用户业务当前口径，不用旧价格推算收入。

同时保留首次获知渠道、直接引流作品、影响决策内容；一条线索可能受多条内容影响。能确认作品的单列，只有“来自抖音”的保留为平台级，存在冲突的列待核。不能按播放份额分摊未知线索。

**每千次播放有效线索** = 同一作品、同一观察窗口的确认有效微信线索 ÷ 精确播放次数 × 1000。这是按播放次数计算的产出率，不是观看人数转化概率。归属或窗口不可靠时不算。**加微后咨询率**、**有效线索报名率**只用同一批真实去重的人作分子分母，明确观察成熟度；不同日期/渠道总量不得相除。

D7 可看早期线索，D30 或业务适合的窗口看咨询与成交。窗口未满可展示当前累计，但不与完整窗口直接判优；晚归属、退款和更正应追加记录。

## 何时取数、如何比较

默认建议以发布约 24 小时、72 小时、7 天观察内容表现，再按线索业务周期看 30 天。用户已有时间安排优先，已有任务由原任务采集；不创建重复轮询。定时唤醒失败或数据晚更新时记录实际经过时间，不能补造错过的历史点。

比较顺序：同账号、相近题材/长度、相同发布年龄和流量条件的历史分布 → 同批次候选 → 跨账号爆款的创意参考。历史累计爆款不是首日及格线，也不只挑成功样本。基线记录纳入、排除和缺失的完整范围。

先报告绝对值、差值、分母与样本规模。百分比相差用百分点；同一作品不同快照可算累计增长，跨作品累计数不可当小时增长。样本少或归属覆盖不足时保留方向性判断；不设脱离业务的“播放 1000 就显著”规则。

## 从数据到下一轮改法

沿观众路径诊断，不把所有指标合成一个看似精确的总分：

1. 曝光弱、留存尚好：检查选题覆盖、账号人群、平台分发与时间，不能直接归咎于剪法。
2. 开头掉人：对照实际前 2/3/5 秒的原话、画面和标题承诺，提出一个可测试的开头改法。
3. 早期留存尚好、观看秒数弱：查 5—30 秒承接及实际曲线掉点；没曲线就只列待验证解释。
4. 播放和留存好、有效线索弱：查目标人群、CTA 相关性、资料是否兑现、承接是否及时和归属是否缺失。
5. 线索多但咨询/报名弱：检查线索质量与后端过程，不把低质量领取当成功引流，也不能直接认定是剪辑失败。

给出 1—3 个具体实验：目标人群、假设、只改哪个主要变量、保留哪些内容、首要指标、观察窗口、样本/停止条件与负面信号。例如比较“先报薪资”和“先讲真实选择困难”，其余题材与时长尽量匹配；不要在同一账号重复发布相同内容制造伪随机 A/B。

未随机分配的不同视频只支持相关性和复验方向。检验留存可用其实际统计分母与不确定性区间；检验人数转化用同群体人数。只有平台百分比没有其统计分母时，不以播放量硬套显著性。

报告先说业务结论，再给证据表、较可能的解释、未知与下一步。区分“开头表现较好”“更会带来线索”和“方法已稳定有效”。
