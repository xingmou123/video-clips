# 从素材到完整切片

## 选择值得剪的一段

先弄清素材类型与目标观众。学员分享、求职连麦、技术教学、管理讨论可能服务不同人群，不能只凭薪资高低或主持人情绪选段。

候选写明：目标观众、具体问题、最有吸引力的原话/画面、后面能兑现的解释、来源起止时间、适合的联系理由。优先“真实困境 + 可用判断或方法 + 具体证据”的完整单元；没有足够正文的强金句只适合预告，不能伪装完整干货。

选题可来自职业选择、薪资成长、工程问题、学习路径、行业变化。技术内容也能有传播力，例如先展示故障、异常波形或容易误解的结果，再解释；不要求每条都用冲突、焦虑或收入刺激。

## 开头与承接

- 前三秒让观众知道这与自己有什么关系。真实问题、代价、反常结果优先于寒暄、目录、人物介绍；薪资数字后要尽快说清真正的选择和顾虑。
- 可以前置同一话题里有吸引力的原话，再接回问题与回答。先核对人物、指代、否定词、时间、因果，避免把不同话题拼成一句新主张。
- 前 5—30 秒开始提供判断或具体信息。不要用多个悬念卡拖到正文才回答；问题重述只保留理解所需部分。
- “先讲痛点”是候选策略，不是三秒必胜公式。按实际掉点与观众反馈调整，不能在没有曲线时指定某秒是流失原因。

## 正文取舍

保留问题、核心回答、依据、具体实例、适用条件与结论。优先删无信息停顿、口头重复、无关岔路；保留能帮助理解的停顿和追问。前后必须听起来像正常交流。

长短服从价值密度和完整性。长内容可先做完整主片，再在用户需要时做独立短版；不要仅为提高整片完播率删掉关键干货。平均观看秒数、观看占比和完播率联合判断，不能只优化一个指标。

技术结论回到原话或工程证据；“我负责”“预计涨薪”“签约”“入职”“到账”不可相互替代。公开处理个人经历时沿用素材已有的授权范围和匿名方式。

## 画面与声音

- 根据交付平台和已有风格选择比例、人物布局、字号与留白；不要凭一个案例固化所有视频的字体、颜色或时长。
- 保留有解释作用的代码、PPT、板卡、波形和演示，做到字可读、指向清晰。补图应展示因果、流程或对比，不能把原话换成几张重复名词的卡片。
- 字幕区与重点字分工明确，重点少而准；人物、屏幕内容与平台界面遮挡要实际检查。不要默认叠灰罩、挤占正文或用连续大字卡替代现场。
- 先保障人声清楚、音量连贯。变速、配乐、降噪需要实际听感支持，避免过度处理损害自然表达。
- 自动转写只提供候选文本和时间线。术语、数字、否定词与说话人须对音频核实；转写分段时间不能直接当最终剪点。
- 已有与原片同版本的整理字幕时可显式复用，保留原件。SRT/VTT 的句内字词时间通常是估算，不能冒充音频强制对齐；先检查重叠、乱序、越界，修订只作用于工作副本并留依据。画面缩放、窗口切换时重新检查隐私裁切，不能靠一张截图确认全片。

## 可检查的交付

至少保留原片标识、来源版本、源时间→成片时间的剪辑表、字幕、完整 MP4、实际使用的开头和结尾、方法版本。剪辑表可沿用现有格式，不强迫另建同义台账。

重复分析可复用同源同版本的转写和渲染缓存；源片、字幕、切点、模型或样式改变后，确认缓存仍匹配。已选定的片段单独保存，再次运行高光检测可能改变结果，不能将重新检测当成执行原计划。导出先写临时文件，编码成功后再替换当前文件；保留已完成片段供中断后接续。

检查与改动相称：

1. 用 ffprobe 或等效工具确认时长、分辨率、音视频轨道；完整解码检查技术损坏。
2. 实际听看开头、所有重排/重要删改接缝、关键论证与收尾；看字幕是否截字、越界、不同步。大幅重排时完整听看成片。
3. 对数字、技术词、否定词、指代和 CTA 做针对性核对。只抽帧就写“画面抽查”，没有听过不写“音频核对通过”。
4. 向用户交可打开的完整视频；开头预览和候选片要明示。上传时核对文件指纹与本次主片，防止发布旧版。

机器告警用于定位复查：静态代码/PPT/简历可能触发冻结检测，术语匹配和所谓平台风险词也可能误报。回到具体区间与上下文核对，不为消告警添加无意义运镜、删除技术结论或编造平台规则。检测失败或报告为空不算通过；自动修复另存候选，重检后同时核对内容和字幕时间，改善后才替换，不能只凭告警数减少判定成功。

剪辑软件、FFmpeg、字幕渲染方式可替换。若素材清晰度或工具限制阻碍交付，先完成能完成的部分并给出具体缺口，不能以脚本成功替代成片可用。
